# 以撒灾难饥饿游戏：玩法与地图规划

记录日期：2026-10-11。

## Goal

通过以撒灾难模组与数据包，复用并改造现成饥饿游戏地图，在包含游戏大厅的存档中提供箱子随机以撒道具、泪弹与 MC PvP 混合战斗、可破坏场地和不定期怪物压力。

## Current Phase

Phase 1 已完成：保存目前的需求与讨论。后续阶段尚未开始，当前没有执行地图改造或模组开发。

本轮交付仅为 planning-with-files 规划记录；下列后续阶段是路线草案，不表示已确定全部技术方案。

## Confirmed Requirements

- 玩法组合：饥饿游戏 + 全图可破坏 + 以撒灾难模组。
- 玩家从箱子中获得以撒道具，主要战斗方式为泪弹与原版 MC PvP 的混合。
- 场地不定期刷新怪物，增加玩家压力。
- 优先复用他人的饥饿游戏地图，裁剪比赛区域并整合进带大厅的目标存档。
- 初版竞技场下方采用虚空；可以炸穿或挖穿地形后掉出场地，不采用不可破坏底板作为初版默认方案。
- 地图过薄和过厚都需要处理；地下厚度尚未确定。
- 本次需求是保存规划，没有要求安装工具、修改模组代码或操作游戏存档。
- 用户后续要求将临时资料集中放到 temp/ 下的本项目子目录；本玩法使用 temp/isaac-hunger-games/，规划记录仍位于本目录。

## Proposed Approaches — 尚未确认

- 大厅、比赛竞技场、用于恢复的原始模板分开；竞技场独立维度是候选方案。
- 初版先做一个大厅、一张地图；后续再考虑地图轮换。

- 数据包负责规则和内容配置；模组负责能力与必要的底层接口。
