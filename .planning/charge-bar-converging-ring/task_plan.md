# 蓄力条收缩圆环

> 执行使用 `planning-with-files` 维护本子项目；遵守项目现有资源及验证约定，仅运行 `runData`，不额外执行 compile／build／游戏任务。

## 目标与授权

用户要求所有蓄力条增加细白圆环：蓄力开始出现，进度增加时向图标收缩。最新反馈要求更低不透明度、更近初始位置及满蓄力隐藏白环。现有填充显示保留，统一适用于当前与未来注册的栏。

## 方案

- 在 `ChargeBarHudOverlay` 的共用绘制流程加入白色几何圆环，不按道具／栏 ID 枚举。
- 圆环线宽 1 GUI 像素、不透明度约 50%；开始时距图标外缘约 4 GUI 像素，靠近完成时收缩到图标外缘，蓄满即隐藏。
- 半径由现有归一化进度线性计算，不新增网络包、注册字段或运行时动画状态。
- 所有白环先批量绘制，再绘制现有底图与填充；原布局／优先级／闪烁／持头和正进度条件保持。
- 缓存圆周坐标，用共享 GUI 顶点缓冲绘制 64 段薄环，无新增 PNG 或临时生成脚本。

## 验收

- 半径随 0→1 单调收缩；白环仅在 0 < progress < 1 时绘制，蓄满和继续保持满蓄力均隐藏。
- 普通攻击、终末天启及未来栏均共用相同路径，各自使用各自进度。
- 正进度且持 IsaacHead 时显示；取消、释放、清空或不持头时与图标一起隐藏。
- 多栏排序和位置不变，白环先于全部图标绘制。
- 实际客户端检查 GUI 比例、线宽、多个收缩环重叠及满蓄力接触感；未执行则明确报告。
