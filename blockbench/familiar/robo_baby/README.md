# 机械宝宝（RoboBaby）

保留已确认的加大躯干、左右双色拼接和缩短脖子的版本。

- `robo_baby.bbmodel`：Blockbench 可编辑源文件，内嵌完整贴图、图层、骨架和动画。
- `robo_baby.png`：正式贴图，128×64；逻辑 UV 128×64。
- `RoboBabyModel.java`：Forge 1.20.1 / Mojang mappings 模型导出参考。
- `RoboBabyAnimations.java`：动画导出参考。

动画：`idle` 1 秒循环。

这些文件为美术源文件和导出参考；Java 文件尚未在此目录中接入实体或进行游戏内验证。
