# 机器宝宝（MachineBaby）

使用已确认的描边版本，保留用户补充的眼部细节、嘴部轮廓、额头接缝及补齐的后脑。

- `machine_baby.bbmodel`：Blockbench 可编辑源文件，内嵌完整贴图、图层、骨架和动画。
- `machine_baby.png`：正式贴图，256×128；逻辑 UV 128×64。
- `MachineBabyModel.java`：Forge 1.20.1 / Mojang mappings 模型导出参考。
- `MachineBabyAnimations.java`：动画导出参考。

动画：`idle` 1 秒循环。

这些文件为美术源文件和导出参考；Java 文件尚未在此目录中接入实体或进行游戏内验证。
