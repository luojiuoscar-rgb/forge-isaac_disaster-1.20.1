# 玛姬姐妹（SisterMaggy）

保留已确认的描边精修和侧面、背面纹理。

- `sister_maggy.bbmodel`：Blockbench 可编辑源文件，内嵌完整贴图、图层、骨架和动画。
- `sister_maggy.png`：正式贴图，64×64；逻辑 UV 64×64。
- `SisterMaggyModel.java`：Forge 1.20.1 / Mojang mappings 模型导出参考。
- `SisterMaggyAnimations.java`：动画导出参考。

动画：`idle` 1 秒循环；`attack` 0.8 秒单次。

这些文件为美术源文件和导出参考；Java 文件尚未在此目录中接入实体或进行游戏内验证。
