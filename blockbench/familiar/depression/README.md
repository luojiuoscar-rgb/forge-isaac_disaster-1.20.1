# 抑郁症（Depression）跟班模型

`depression.bbmodel` 是可编辑美术源文件。最终几何、UV、像素贴图及导出均通过 Blockbench MCP 在 Blockbench 内完成；不依赖模型生成脚本。直接打开此文件即可继续编辑。

- `depression.png`：64×64 单张不透明颜色贴图，同时内嵌在源模型中。
- `depression.obj` / `depression.mtl`：同一项目通过 Blockbench 原生 OBJ 编码器导出的网格与材质，PNG 与其放在同一目录。
- `reference.png`：用户提供的原始二维参考，后续调整时应持续对照。
- `preview_surface_relief.png`：当前正反面浅云卷的对照。

当前正式文件已采用用户确认的单一连续网格版，保留左高峰、右低肩、下方两段宽弧与浅凹。已移除 `cloud_side_puff` 和两个体块相交形成的接缝。正反两个大面各有两处错位、宽而浅的云卷，直接由同一表面的控制点塑造；没有叠加独立小球或胶囊。较浅的灰紫像素高光与局部下缘阴影配合几何表现起伏，正面下部暗带已减弱中段，避免形成完整的嘴形。

## 美术规格

- 目标：Forge 1.20.1 Java 版桌面端跟班；兼顾外观与多实例的几何成本。
- 格式：Generic Model / `free`；1 个网格 `cloud_body`，1 个根组 `cloud_root`。
- 几何：91 个顶点、42 个四边形及 94 个三角形，三角化后共 178 个三角面。整个网格为一个闭合连通分量；表面控制点只用于需要改变受光和厚度的浅凸起。
- 包围尺寸：约 11.34 × 8.20 × 6.60 模型单位；1 个模型单位按 Minecraft 的 1/16 格约定设计，实际运行缩放由后续渲染器决定。
- 材质：单张不透明漫反射颜色图，无 PBR、透明叠层或发光材质。
- UV：正反面分别使用按模型 XY 坐标投影的区域，投影平面为 2 像素/模型单位。曲面上的实际密度随倾角变化；侧向表面有意采样纯色色块。贴图仅承载宽幅像素明暗，不使用需要等比例保真的高频图案。
- 法线：网格使用 `smooth`，原生 OBJ 导出保存 91 条顶点法线；运行时转换需保留这些法线，才能保持编辑器中的柔和受光。
- 动画：本次为静态模型；根组转轴位于云体中心附近，便于以后整体漂浮和转向。

## 检查与使用边界

已检查纯色及贴图状态下的正面、斜侧面与背面，并检查侧面预览及原始参考。整个网格只有一个连通分量，所有边连接两个面，没有零面积三角形，UV 数值有限且在贴图范围内。外部 PNG 与模型内嵌 PNG 一致。OBJ 为同一模型的原生导出，保存 136 个面、91 条顶点法线，三角化计数为 178。原生源文件已重新打开，确认几何、贴图与平滑法线设置保留。

本目录保存美术资产，尚未注册跟班或接入 Minecraft 渲染器，也未进行游戏内视觉或性能测试。后续若接入运行时，可参照妈妈的菜刀的自由网格转换方式；不要直接将自由网格导出为只支持方块部件的 Java 实体模型。
