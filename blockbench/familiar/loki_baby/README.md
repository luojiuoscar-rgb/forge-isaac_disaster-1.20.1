# 洛基宝宝（Loki Baby）

用于 Isaac Disaster / Minecraft Forge 1.20.1 的跟班模型资产。

- `loki_baby.bbmodel`：可编辑模型，保留贴图层、骨骼与最终确认的两个动画。
- `loki_baby.png`：64×64 像素贴图，与源模型内嵌贴图一致。

模型包含 19 个方块、9 个骨骼分组；保留贴身的双层小翅膀及已确认的描边、正反面材质，大翅膀保持上移一格的最终位置。

四块角几何归属于 `head`；修正归属时保留了原有中立位置、UV、贴图层和动画关键帧。运行时头部保持中立平视，不独立转头或俯仰，随本体播放旋转动作；泪弹方向仍支持玩家的俯仰瞄准。

`animation.idle` 为 1 秒循环，包含轻微浮动与翅膀随动；`animation.attack` 为 0.6 秒单次播放，包含反向蓄力、跃起旋转一周、旋转减速与落地回弹。源模型中的动画关键帧未作修改。

以撒头的持续输入只负责触发新一轮攻击；触发时记录玩家目视方向并开始动作，第 3 tick 同时发射四颗泪弹并播放发射音效，随后完整播放旋转收尾。起手后松开、再次按下或切换手持物均不会取消或重启这一轮；松开后不再触发下一轮。连续出弹仍间隔 15 tick，召回仍会清除尚未发射的动作并保留剩余冷却。

目标工作区分支为 `feature/feature-b`。此目录保留可编辑源模型和贴图；模型与动画 Java 可从 `.bbmodel` 重新导出，不额外保存参考副本。游戏运行时使用 `src/main` 中经过适配的独立模型、动画与渲染注册。
