# 圣遗物（Relic）

恢复原版粗黑描边、端部轮廓和蓝色明暗，保留完整原版贴图及 4 个图层。整体围绕中心等比缩小为原版的 62.5%，尺寸为 9.375×11.25×1.875 个模型单位。

- `relic.bbmodel`：可编辑源文件，几何与 UV 同比例缩小，原图像素映射保持一致。
- `relic.png`：原版 64×64 贴图；缩小模型的逻辑 UV 为 40×40。
- `RelicModel.java`：Forge 1.20.1 / Mojang mappings 模型参考，保留原版整数 UV，并对根节点施加固定缩放，使外观与源文件一致。

7 个方块，1 个骨骼分组，84 个三角面。静态模型，无动画。Java 文件尚未接入游戏实体。
