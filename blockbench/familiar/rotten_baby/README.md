# 腐烂宝宝（RottenBaby）

保留已确认的头部残缺及露出的头骨。

- `rotten_baby.bbmodel`：Blockbench 可编辑源文件，内嵌完整贴图、图层、骨架和动画。
- `rotten_baby.png`：正式贴图，128×64；逻辑 UV 128×64。
- `RottenBabyModel.java`：Forge 1.20.1 / Mojang mappings 模型导出参考。
- `RottenBabyAnimations.java`：动画导出参考。

动画：`idle` 1 秒循环；`attack` 0.8 秒单次。

这些文件为美术源文件和导出参考；Java 文件尚未在此目录中接入实体或进行游戏内验证。
